## しくみ

**ジョブ**（実行したい処理。コンテナイメージで用意する）を**ジョブキュー**に投入すると、AWS Batch が必要な計算資源（**コンピューティング環境**）を自動で起動して実行し、終わったら片付けます。

- コンピューティング環境には [[ec2]]（スポットインスタンスも可）か [[fargate]] を選べる
- ジョブ同士の依存関係（A が終わったら B）や、配列ジョブ（同じ処理を大量に並列実行）を扱える

## 試験でのポイント

- 「大量のバッチ処理」「数時間かかる計算」「HPC」→ AWS Batch
- [[lambda]] の 15 分制限を超える処理の受け皿になる
- 中断されてもやり直せるジョブなら、**スポットインスタンス**と組み合わせてコストを大きく下げられる
- AWS Batch 自体は無料。使った EC2・Fargate の料金だけがかかる

## よくあるひっかけ

- 決まった手順の複数ステップをつなぐだけなら [[step-functions]]。Step Functions から Batch のジョブを呼ぶ組み合わせもある
- 定期実行のきっかけは [[eventbridge]] のスケジュールで作る
