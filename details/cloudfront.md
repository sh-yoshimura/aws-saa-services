## しくみ

世界中に数百ある**エッジロケーション**にコンテンツをキャッシュし、利用者の近くから配信する **CDN** です。キャッシュに無いときは**オリジン**（元のサーバー）から取得します。

- オリジンの例：[[s3]]、[[elb]]、[[ec2]]、[[api-gateway]]、オンプレミスのサーバー
- 静的コンテンツだけでなく、動的コンテンツや API の高速化にも使える（AWS のネットワークを通るため）
- HTTPS 対応。証明書は [[acm]]（CloudFront 用の証明書は**バージニア北部（us-east-1）**で発行）

## 主な機能

- **OAC（オリジンアクセスコントロール）**：S3 バケットへのアクセスを CloudFront 経由だけに制限する（旧 OAI）
- **署名付き URL／署名付き Cookie**：有料コンテンツなど、許可した利用者だけに配信する
- **地域制限（ジオブロッキング）**：特定の国からのアクセスを拒否・許可する
- [[waf]] と [[shield]] を組み合わせて、エッジで攻撃を防ぐ
- **CloudFront Functions / Lambda@Edge**：エッジでリクエストやレスポンスを加工する
- **オリジンフェイルオーバー**：プライマリのオリジンが異常なら、セカンダリから配信
- **キャッシュの無効化（Invalidation）**：更新したファイルのキャッシュを消す

## 試験でのポイント

- 「世界中の利用者に、静的コンテンツを低レイテンシーで配信」「オリジンの負荷を下げたい」→ CloudFront
- 「S3 に直接アクセスさせず、CloudFront 経由だけにしたい」→ **OAC**
- 「会員だけに動画を配信」→ **署名付き URL／Cookie**

## よくあるひっかけ

- キャッシュしない TCP/UDP のアプリ（ゲーム、VoIP）や固定 IP が必要な場合は [[global-accelerator]]
- S3 の **Transfer Acceleration** は「アップロード」の高速化。配信の高速化は CloudFront
