## しくみ

インフラの構成を**テンプレート**（JSON / YAML）に書き、その内容どおりにリソースを自動で作成・変更・削除します（**Infrastructure as Code**）。

| 用語 | 意味 |
|---|---|
| **テンプレート** | 作りたいリソースと設定を書いたファイル（Parameters、Resources、Outputs など） |
| **スタック** | テンプレートから作られたリソースのまとまり。まとめて更新・削除できる |
| **変更セット** | 更新する前に、何が変わるか（作られる・置き換えられる・削除される）を確認する |
| **StackSets** | 1 つのテンプレートから、**複数のアカウント・リージョン**にスタックを一度に作る |
| **ドリフト検出** | 手作業で変更されて、テンプレートとずれたリソースを見つける |

- 作成に失敗すると、標準では自動でロールバック（元に戻す）する
- **DeletionPolicy**：スタックを削除しても、DB などを残す・スナップショットを取る
- CloudFormation 自体は無料。作られたリソースの料金がかかる
- AWS CDK を使うと、プログラミング言語でテンプレートを作れる

## 試験でのポイント

- 「同じ環境を何度でも作りたい」「別のリージョンに同じ構成を作りたい（災害対策）」「手作業のミスをなくしたい」→ CloudFormation
- 「複数のアカウント・リージョンに一括で展開」→ **StackSets**
- 「本番を更新する前に影響を確認」→ **変更セット**

## よくあるひっかけ

- アプリのデプロイを手早く行いたいだけなら [[elastic-beanstalk]] のほうが簡単（裏では CloudFormation を使っている）
