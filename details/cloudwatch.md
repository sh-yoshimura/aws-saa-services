## しくみ

AWS のリソースやアプリを**監視**するサービスです。いくつかの機能の集まりです。

| 機能 | 内容 |
|---|---|
| **メトリクス** | CPU 使用率、リクエスト数などの数値。多くのサービスが自動で送る。EC2 の標準は 5 分間隔（詳細モニタリングで 1 分） |
| **アラーム** | メトリクスがしきい値を超えたら、[[sns]] で通知、[[ec2-auto-scaling]] でスケール、EC2 の停止・再起動・復旧などを行う |
| **Logs** | アプリや AWS サービスのログを集めて保存・検索する。**Logs Insights** でクエリ、**メトリクスフィルター**でログから数値を作る |
| **ダッシュボード** | グラフをまとめて表示する |
| **CloudWatch エージェント** | EC2 やオンプレミスから、**メモリ・ディスク使用率**やログを送る |
| その他 | Synthetics（外形監視）、Container Insights、Application Signals など |

## 試験でのポイント

- 「CPU 使用率が高くなったら通知・スケール」→ CloudWatch アラーム
- 「EC2 の**メモリ使用率**やディスクの空きを監視したい」→ **CloudWatch エージェント**を入れる（標準のメトリクスには無い）
- 「ログに特定のエラーが出たら通知」→ CloudWatch Logs の**メトリクスフィルター**＋アラーム
- ログを長期間安く保存 → [[s3]] へエクスポート（保持期間も設定できる）

## よくあるひっかけ

- 「誰がその操作をしたか」は CloudWatch ではなく [[cloudtrail]]
- 「設定がどう変わったか」は [[config]]
