## しくみ

AWS のリソースの**設定**を記録し続け、**いつ・どう変わったか**の履歴と、**ルールに沿っているか**の評価を提供します。

- **設定の記録**：セキュリティグループのルール、S3 バケットのポリシーなどの変更を、時系列で残す（変更を行った API は [[cloudtrail]] と関連付けて見られる）
- **Config ルール**：設定がルールに沿っているか（準拠／非準拠）を評価する
  - **マネージドルール**：AWS が用意したもの（例：「S3 バケットが公開されていない」「EBS が暗号化されている」「SSH が全開放されていない」）
  - カスタムルール：[[lambda]] や Guard で自分で書く
- **修復アクション**：非準拠になったら、[[systems-manager]] Automation で自動的に直す
- **適合パック**：ルールと修復アクションをまとめたもの
- **アグリゲーター**：複数のアカウント・リージョンの結果を 1 か所にまとめる

## 試験でのポイント

- 「リソースの設定変更の履歴を見たい」「設定がコンプライアンスに準拠しているか継続的に評価したい」→ Config
- 「非準拠の設定を自動で修正」→ Config ルール＋**修復アクション**（Systems Manager Automation）

## よくあるひっかけ

- Config は違反を**防ぐ**ものではなく、**見つけて（直す）**もの。そもそも操作を禁止したいなら [[organizations]] の SCP や IAM ポリシー
- 「誰が変えたか」は CloudTrail で確認する
