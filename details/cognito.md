## しくみ

自分で作る Web・モバイルアプリに、**利用者の登録・ログイン機能**を付けるサービスです。2 つの部品があります。

| 部品 | 役割 | 結果 |
|---|---|---|
| **ユーザープール** | 利用者の**認証**（サインアップ、サインイン、MFA、パスワードの再設定）。Google・Apple・SAML などの外部 ID でのログインにも対応 | JWT トークンを発行 |
| **ID プール**（フェデレーテッドアイデンティティ） | 認証された利用者（やゲスト）に、**AWS のリソースへの一時的な権限**を渡す | 一時的な AWS 認証情報（IAM ロール） |

## よく使う組み合わせ

- ユーザープール ＋ [[api-gateway]] / [[elb]]（ALB）：ログインした利用者だけに API を使わせる
- ID プール：モバイルアプリから直接 [[s3]] に画像をアップロードする、[[dynamodb]] に書き込む

## 試験でのポイント

- 「アプリの利用者のサインアップ・サインイン」「ソーシャルログイン」「数百万人の利用者」→ **ユーザープール**
- 「モバイルアプリの利用者に、S3 や DynamoDB への一時的なアクセス権を与えたい」→ **ID プール**

## よくあるひっかけ

- 利用者ごとに IAM ユーザーを作る選択肢は誤り。IAM ユーザーの数には上限があり、利用者の管理には使わない
