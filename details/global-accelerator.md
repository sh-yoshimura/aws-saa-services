## しくみ

**2 つの固定のエニーキャスト IP アドレス**を提供し、利用者の通信を最寄りのエッジロケーションで受け取ります。そこから先は AWS のグローバルネットワークを通って、最適なリージョンのエンドポイントへ届けます。

- エンドポイント：[[elb]]（ALB / NLB）、[[ec2]]、Elastic IP
- **ヘルスチェック**で異常なリージョンを外し、**数十秒以内**に別のリージョンへ切り替える（DNS のキャッシュに左右されない）
- TCP と UDP の両方に対応。キャッシュはしない

## CloudFront との違い

| 項目 | [[cloudfront]] | Global Accelerator |
|---|---|---|
| キャッシュ | する | **しない** |
| 主な対象 | HTTP(S) のコンテンツ配信 | **TCP/UDP** のアプリ全般 |
| IP アドレス | 変わる | **固定（2 つ）** |
| 向いている用途 | Web サイト、動画、静的ファイル | ゲーム、IoT、VoIP、固定 IP が必要な API |

## 試験でのポイント

- 「固定 IP をクライアントの許可リストに登録したい」「複数リージョンの ALB に」→ Global Accelerator
- 「リージョン障害時に、DNS の TTL を待たずに素早く切り替えたい」→ Global Accelerator
- 「UDP」「ゲーム」「世界中のユーザー」→ Global Accelerator

## よくあるひっかけ

- 静的なコンテンツをキャッシュして配信したいなら CloudFront。Global Accelerator は経路を速くするだけ
