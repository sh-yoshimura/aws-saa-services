## しくみ

AWS アカウントの中の**不審な動きや脅威**を、機械学習と脅威インテリジェンスで継続的に検出するサービスです。有効化するだけで動き、エージェントの導入は不要です。

分析するデータの例：

- [[cloudtrail]] の管理イベント・S3 のデータイベント
- VPC フローログ
- DNS のログ
- EKS の監査ログ、RDS のログイン、Lambda のネットワーク、EBS のマルウェアスキャン など（オプション）

検出の例：

- 普段と違う場所からの API 呼び出し、認証情報の不正利用
- EC2 が暗号資産のマイニングや、既知の悪質な IP と通信している
- S3 バケットのポリシーが急に公開された

## 試験でのポイント

- 「脅威を検出」「不審なアクティビティ」「侵害されたインスタンス」「最小の運用負荷で」→ GuardDuty
- 検出結果を [[eventbridge]] で受けて、[[lambda]] で自動対応（インスタンスの隔離など）や [[sns]] で通知する
- [[organizations]] で、組織全体の GuardDuty を 1 つのアカウントでまとめて管理できる

## よくあるひっかけ

- GuardDuty は検出するだけで、攻撃をブロックはしない（ブロックは WAF、ネットワーク ACL など）
- ソフトウェアの脆弱性の検査は [[inspector]]、機密データの検出は [[macie]]
