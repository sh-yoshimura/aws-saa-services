## しくみ

[[s3]] に置いたデータに対して、**取り込まずにその場で SQL を実行**するサービスです。サーバーの用意は不要で、**スキャンしたデータ量**で課金されます。

- 対応する形式：CSV、JSON、**Parquet**、**ORC**、Avro など
- テーブルの定義（どこに・どんな形のデータがあるか）は [[glue]] の**データカタログ**を使う
- **フェデレーテッドクエリ**：DynamoDB、RDS などのデータにもクエリできる
- 結果は S3 に保存され、[[quicksight]] で可視化できる

## コストと速度を改善する方法（頻出）

- **列指向の形式（Parquet / ORC）に変換**する：必要な列だけを読むので、スキャン量が減る
- **圧縮**する
- **パーティション**に分ける（例 `year=2026/month=11/`）：条件に合うフォルダーだけを読む

## 試験でのポイント

- 「S3 のログ（CloudTrail、ALB、VPC フローログ）を SQL で分析」「アドホックなクエリ」「サーバーレス」「最小の運用負荷」→ Athena
- 「Athena のコストを下げたい」→ Parquet などに変換、パーティション分割

## よくあるひっかけ

- 大量のデータに対して、決まった重い集計を何度も高速に実行するなら [[redshift]]
- Athena はデータを更新する業務システムの DB には向かない
