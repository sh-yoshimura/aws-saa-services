## しくみ

オンプレミスに**ゲートウェイ**（仮想マシンか専用機）を置き、オンプレミスのサーバーからは今までどおりのファイル共有・ディスク・テープとして見せながら、データを AWS に保存します。よく使うデータはゲートウェイにキャッシュされます。

| 種類 | オンプレミスからの見え方 | 保存先 |
|---|---|---|
| S3 File Gateway | NFS / SMB のファイル共有 | [[s3]] のオブジェクト |
| FSx File Gateway | SMB のファイル共有 | [[fsx]] for Windows File Server |
| Volume Gateway | iSCSI のディスク（キャッシュ型／保管型） | S3（EBS スナップショットとして） |
| Tape Gateway | 仮想テープライブラリ（VTL） | S3 / [[s3-glacier]] |

## 試験でのポイント

- 「オンプレミスのアプリを変えずに、クラウドのストレージを使いたい」「ハイブリッド」→ Storage Gateway
- 「物理テープのバックアップをやめたい」「既存のバックアップソフトを使い続けたい」→ **Tape Gateway**
- 「オンプレミスのファイルを S3 に保存して、AWS 側の分析にも使いたい」→ **S3 File Gateway**

## よくあるひっかけ

- 一度きりの大量データ**移行**なら [[datasync]] や [[snow-family]] のほうが合う。Storage Gateway は**使い続ける**ための仕組み
