## しくみ

データを集めて、分析しやすい形に整える **ETL（抽出・変換・ロード）**のためのサーバーレスなサービスです。

| 機能 | 内容 |
|---|---|
| **データカタログ** | どこに・どんな形（スキーマ）のデータがあるかを管理する、メタデータの置き場所。[[athena]]、[[redshift]] Spectrum、[[emr]] から使える |
| **クローラー** | S3 などのデータを自動で調べ、データカタログにテーブルを作る |
| **ETL ジョブ** | Apache Spark（または Python）で、データを変換する。CSV から Parquet への変換など |
| **Glue DataBrew** | コードを書かずに、画面操作でデータを整える |
| **ジョブブックマーク** | 前回処理したところを覚えて、新しいデータだけを処理する |

## 試験でのポイント

- 「ETL」「データの形式を変換」「サーバーレスで」→ Glue
- 「S3 のデータのスキーマを自動で検出して、Athena で検索したい」→ Glue **クローラー**＋**データカタログ**
- 「Athena のコストを下げるために Parquet に変換」→ Glue の ETL ジョブ

## よくあるひっかけ

- Spark や Hadoop のクラスターを自分で細かく調整して動かしたいなら [[emr]]
- ストリーミングデータを届ける途中で変換するだけなら [[data-firehose]]
