## しくみ

複数の企業（Anthropic、Amazon、Meta、Mistral AI など）の**生成 AI の基盤モデル**を、1 つの API から利用できるサーバーレスのサービスです。モデルのサーバーを自分で用意する必要はありません。

- **ナレッジベース**：社内の文書（S3 など）を検索して、その内容に基づいて回答させる（RAG）
- **エージェント**：複数の手順を、API を呼び出しながら自動で進める
- **ガードレール**：不適切な入力・出力や、個人情報をブロックする
- **ファインチューニング**：自社のデータでモデルを調整する
- 入力したデータは、基盤モデルの学習には使われない。VPC エンドポイント（PrivateLink）で非公開に接続できる

## 試験でのポイント

- 「生成 AI をアプリに組み込みたい」「基盤モデルを API で使いたい」「インフラの管理なしで」→ Bedrock
- 「社内文書に基づいて回答するチャットボット」→ Bedrock のナレッジベース
