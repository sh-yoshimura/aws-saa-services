## しくみ

**テキストを音声に変換する（音声合成、TTS：Text-to-Speech）**、学習済みの AI サービスです。API にテキストを渡すと、人が話しているような音声が返ってきます。機械学習のモデルを作ったり学習させたりする必要はありません。

- 日本語を含む多くの言語に対応し、言語ごとに男性・女性などの複数の**声**から選べる
- 出力形式：MP3、OGG（Vorbis / Opus）、PCM
- 料金：変換した**文字数**に応じて課金（声の種類＝エンジンによって単価が違う）

## 変換のしかた

| 方法 | 動き | 向いている場面 |
|---|---|---|
| **リアルタイム（同期）** | API を呼ぶと、その場で音声が返ってくる（ストリーミングで再生しながら受け取れる） | 短い文章、アプリの音声応答 |
| **非同期タスク** | 変換を依頼すると、できた音声ファイルが [[s3]] に保存される。完了は [[sns]] で通知できる | ニュース記事・電子書籍など**長い文章** |

## 声の種類（エンジン）

| エンジン | 特徴 |
|---|---|
| スタンダード | 従来の方式。安い |
| **ニューラル** | 深層学習による、より自然な音声。ニュースキャスター風などの話し方も選べる |
| ロングフォーム | 長い文章を聞きやすく読むための声 |
| 生成 AI（ジェネレーティブ） | 生成 AI による、さらに表現の豊かな声 |

対応する言語・声はエンジンごとに違います（最新の一覧は公式ドキュメントで確認を）。

## 読み方を調整する機能

- **SSML**（音声合成マークアップ言語）：テキストにタグを付けて、間（ポーズ）、話す速さ、声の高さ、音量、強調、数字や日付の読み方を指定する
  - 例：`<speak>本日は<break time="1s"/>晴れです。</speak>`
- **レキシコン**（発音辞書）：社名・製品名・専門用語の読み方や、略語の読み方を登録する（例：「AWS」を「エーダブリューエス」と読ませる）
- **スピーチマーク**：音声のどの時点で、どの単語・文を読んでいるかの情報を出力する。読み上げに合わせて文字をハイライトしたり、アニメーションの口の動きを合わせたりできる
- **Brand Voice**：企業専用の声を AWS と一緒に作る

## よく使われる場面

- ニュース記事・ブログ・電子書籍の**読み上げ**（音声版を自動で作る）
- 電話の**自動音声案内（IVR）**。Amazon Connect と組み合わせることが多い
- 視覚障がいのある方向けなどの**アクセシビリティ**対応
- e ラーニングの教材、案内放送、IoT 機器の音声

構成の例：記事を [[s3]] に置く → [[lambda]] が Polly で音声に変換 → 音声ファイルを S3 に保存 → [[cloudfront]] で配信

## 似たサービスとの違い（頻出）

AI サービスは「**何を入れて、何が出てくるか**」で覚えます。

| サービス | 入力 | 出力 |
|---|---|---|
| **Amazon Polly** | **テキスト** | **音声** |
| [[transcribe]] | 音声 | テキスト |
| Amazon Translate | テキスト | 別の言語のテキスト |
| [[comprehend]] | テキスト | 感情・キーフレーズなどの分析結果 |
| Amazon Lex | 音声・テキスト（会話） | チャットボットの応答（音声の応答には Polly を使う） |

## 試験でのポイント

- 「テキストを音声に変換」「読み上げ」「音声ファイルを自動で作りたい」「アクセシビリティ」→ **Polly**
- 「社名や専門用語を正しく読ませたい」→ **レキシコン**
- 「間や速さ、強調を調整したい」→ **SSML**
- 「読み上げに合わせて文字を強調表示したい」→ **スピーチマーク**
- 「多言語の音声で案内」→ Translate で翻訳してから Polly で読み上げる

## よくあるひっかけ

- **Polly と Transcribe の向きを逆に覚える。** Polly は「テキスト → 音声」、Transcribe は「音声 → テキスト」
- 翻訳の機能は Polly にはない。別の言語で話させたいなら、先に Amazon Translate で翻訳する
- 会話の意図を理解して応答するのは Amazon Lex。Polly は渡されたテキストを読み上げるだけ
