## しくみ

AWS アカウントで行われた**API 操作の記録**を残すサービスです。コンソールの操作、CLI、SDK、AWS サービスからの呼び出しが対象です。記録には「誰が（IAM ユーザー・ロール）、いつ、どこから（IP）、何を（API）、どのリソースに」が含まれます。

- **イベント履歴**：過去 90 日分の管理イベントは、設定しなくても無料で見られる
- **証跡（トレイル）**：記録を [[s3]] に長期保存し、[[cloudwatch]] Logs にも送れる。**全リージョン**や、[[organizations]] の**組織全体**を対象にできる
- **CloudTrail Lake**：記録を保存して SQL で分析する

| イベントの種類 | 内容 | 標準での記録 |
|---|---|---|
| 管理イベント | リソースの作成・変更・削除など | される |
| データイベント | S3 のオブジェクトの読み書き、Lambda の実行など | **されない**（追加の設定と料金が必要） |
| Insights イベント | 普段と違う量の API 呼び出しを検出 | されない |

## ログを守る

- **ログファイルの整合性の検証**：ログが改ざん・削除されていないかを確認できる
- 保存先の S3 は、MFA 削除やオブジェクトロック、別アカウントへの保存で守る
- [[kms]] で暗号化できる

## 試験でのポイント

- 「誰がリソースを削除したか調べたい」「API 操作を監査したい」→ CloudTrail
- 「S3 のオブジェクトへのアクセスも記録したい」→ **データイベント**を有効にする
- 「重要な操作をすぐに検知して通知」→ CloudTrail ＋ [[eventbridge]] ＋ [[sns]]

## よくあるひっかけ

- CloudTrail は操作の記録。CPU 使用率などの性能の監視は [[cloudwatch]]、リソースの設定の履歴は [[config]]
