## しくみ

複数のセキュリティサービスの**検出結果を 1 か所に集めて**、アカウント全体のセキュリティの状態を確認できるようにします。

- 集める結果：[[guardduty]]、[[inspector]]、[[macie]]、IAM Access Analyzer、AWS Firewall Manager、他社製品など
- **セキュリティ基準のチェック**：AWS の基礎的なベストプラクティス、CIS Benchmarks、PCI DSS などに沿っているかを自動で評価する（[[config]] を使う）
- [[organizations]] と連携して、複数のアカウント・リージョンの結果をまとめる
- [[eventbridge]] と組み合わせて、自動で対応する

## 試験でのポイント

- 「複数のアカウントのセキュリティの状況を一元的に見たい」「セキュリティのベストプラクティスに準拠しているか継続的に確認」→ Security Hub

## よくあるひっかけ

- Security Hub は自分で脅威を検出するというより、**他のサービスの結果を集約・評価する**。脅威の検出そのものは GuardDuty
